# 큐브원 블로그

큐브원 MCP 서버(`cubeone`)의 도구로 네이버 블로그 글을 쓰고 **임시저장 초안**으로 보낸다.
글쓰기 규칙 원문은 서버에 있다. 이 스킬은 순서와 태도만 정한다.

## 도구를 언제 쓰나

| 도구 | 언제 |
|---|---|
| `check_connection` | 처음 연결할 때, 또는 다른 도구가 연결·인증 오류를 낼 때. 확장 프로그램 연결과 네이버 로그인 상태를 사용자에게 그대로 알려 준다 |
| `get_writing_guide` | 글을 쓰기 **전에 매번**. 받은 규칙대로 쓴다 |
| `submit_post` | 사용자가 초안 내용을 확인한 뒤. 기본은 초안(draft) 모드 |
| `get_post_status` | 제출 뒤 처리 결과를 확인할 때 |

## 작업 순서

1. `get_writing_guide`를 호출한다. 규칙을 받기 전에는 글을 쓰지 않는다.
2. 규칙대로 글을 쓰고, 채팅에서 사용자에게 먼저 보여 준다.
3. 사용자가 확인하면 `submit_post`로 초안을 보낸다.
4. 검수(게이트)에서 반려되면 오류에 적힌 이유(줄 번호 등)대로 고쳐서 다시 제출한다. 같은 내용을 그대로 다시 내지 않는다.
5. `get_post_status`로 결과를 확인하고 사용자에게 쉽게 설명한다.

## 지킬 규칙

- **발행하지 않는다.** 항상 임시저장 초안으로만 보낸다. 사용자가 이 글의 발행을 명시적으로 승인한 경우에만 예외다.
- **비밀번호·인증 코드를 묻지 않는다.** 네이버 비밀번호, 2단계 인증 코드, 캡차 답을 요청하거나 입력하지 않는다. 로그인이 필요하면 사용자가 브라우저에서 직접 하도록 안내한다.
- 연결 승인은 사용자가 브라우저 승인 화면에서 「허용」을 직접 누른다. 대신 누르거나 우회하지 않는다.
- 수치·출처·후기를 지어내지 않는다. 모르면 사용자에게 묻는다.
- 글쓰기 규칙을 기억에 의존해 쓰지 않는다. 규칙은 서버에서 바뀔 수 있으니 매번 `get_writing_guide`로 받는다.
